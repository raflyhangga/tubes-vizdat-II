# Tubes Vizdat II

Stack: [Streamlit](https://docs.streamlit.io/get-started/fundamentals/main-concepts)

Create venv
```bash
python3 -m venv .venv
```

Use venv
```bash
# Windows
.venv\Scripts\Activate.ps1

# Linux
source .venv/bin/activate
```

Check if streamline installed correctly
```bash
streamline hello
```

To run the current implementation
```bash
streamlit run main.py
```
